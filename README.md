# OpenKNX Homematic-Gateway 

KNX-Anbindung für Homematic-Thermostate

Von Cornelius Köpp 2024


# Inhalte
 
* [ConfigTransfer](https://github.com/OpenKNX/OFM-ConfigTransfer) Übertragung von Einstellungen
* [OFM-Homematic](https://github.com/OpenKNX/OFM-Homematic) Anbindung von Thermostaten über eine Homematic CCU2 (oder kompatible Zentralen) via XML-RPC   
* [OFM-InternetWeatherModule](https://github.com/OpenKNX/OFM-InternetWeatherModule) - Bereitstellung von Wetterdaten aus dem Internet
